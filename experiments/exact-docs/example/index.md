# Exact Docs

A headless documentation prototype built on Exact. There is no bundled documentation theme.

## Two ways to write

- Write documentation in Markdown.
- Write interactive pages directly in Exact Contract.

Read the [authoring guide](/authoring) or try the [Exact playground](/playground).

## Theme boundary

The layout receives navigation, search results and the current page's table of contents. A future Lenso UI theme can replace that layout without changing the content pipeline.
