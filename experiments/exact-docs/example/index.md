# Exact Docs

Write documentation in Markdown and build interactive pages with Exact. Choose the Lenso theme or keep the presentation headless.

## Two ways to write

- Write documentation in Markdown.
- Write interactive pages directly in Exact Contract.

Read the [authoring guide](/authoring) or try the [Exact playground](/playground).

## Theme boundary

The layout receives navigation, search results and the current page's table of contents. The Lenso theme uses the project’s Exact UI and primitives without changing the content pipeline. Set `theme` to `headless` to supply your own presentation.
