The reference uses the actual refraction maps, material face, inner shade, contour and rim generators, with the production WebGPU optical batch when available. SVG fallback is selectable for diagnosis. It is not a full Menu benchmark. The prototype supports rounded rectangles, default tint, Small and Medium only. Fusion, content lenses, system materials and arbitrary DOM capture are outside this slice.

Measurements run one route at a time in alternating order. Callback time includes canvas painting and GPU submission, not asynchronous GPU execution or browser compositing. Frame intervals are animation-frame opportunities, not proof of presentation.
