# Start at 0.1 and gate 1.0

The first public release is `0.1.0`. Breaking changes during `0.x` still require a Changeset and migration note and advance the minor version; every public release must pass both Certified Consumer Paths. Version `1.0.0` requires all twenty-one initial Foundation Component families, the stable Sidebar Product Primitive and first Sidebar Recipe, stable Light and Dark themes, Theme Scope, token adapter and portal scope contracts, the defined automated and manual accessibility evidence, stable package and registry Release Snapshots and upgrade documentation, and at least one real Lenso Console integration. Console supplies consumer evidence but is not the design-system product boundary.
