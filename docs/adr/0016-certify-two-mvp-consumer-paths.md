# Certify two MVP consumer paths

The MVP supports managed package consumption and editable shadcn Registry consumption. Pull requests validate package exports, Registry schemas and generated source, the Next documentation product, and Chromium component behavior. Framework-specific consumer fixtures and generated smoke projects do not live in this repository; real-product integration evidence is collected when downstream adopters such as Lenso Console migrate. Other channel and framework combinations may work but remain explicitly uncertified until demand justifies expanding the support contract.
