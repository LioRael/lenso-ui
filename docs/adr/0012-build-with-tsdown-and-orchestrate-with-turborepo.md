# Build with tsdown and orchestrate with Turborepo

The monorepo will use Turborepo for its task graph and caching and tsdown as the package bundler instead of introducing Vite into the library build. Before this becomes the release path, an artifact-level proof must demonstrate StyleX transformation, one explicit CSS asset, ESM component subpaths, declarations, preserved client directives, and externalized peers from the real packed output; failure of that proof reopens this decision rather than adding an undocumented fallback pipeline.
