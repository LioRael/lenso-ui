# Apply SemVer to code, tokens, registry, and visual contracts

Component and Product Primitive APIs, public semantic token names, and Registry Item names share one SemVer contract. Removal or incompatible behavior is major; additive public capability is minor; compatible defect, accessibility, and visual corrections are patch. A redesign that materially changes established layout or visual hierarchy is major even when TypeScript continues to compile. Registry source is Consumer-owned after installation, so upgrades provide a source diff and never promise to overwrite local edits automatically.
