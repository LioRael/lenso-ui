# Prove the architecture with one vertical slice

The first implementation slice consists of Button, Text Field, Dialog, and the Sidebar Product Primitive with one Sidebar Recipe. Together they must prove DTCG validation and generation, StyleX and explicit CSS output, canonical source generation into both npm and registry artifacts, Next documentation consumption, Vite registry installation, form behavior, variants and replaceable icons, portal theming and CSP, accessibility, compound composition, and nested left/right Sidebar behavior. The remaining Foundation Component inventory expands only after this slice demonstrates the actual packed and installed artifacts rather than isolated source builds.
