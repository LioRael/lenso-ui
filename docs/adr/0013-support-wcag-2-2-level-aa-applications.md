# Support applications targeting WCAG 2.2 Level AA

Lenso UI will be designed and tested to support applications conforming to WCAG 2.2 Level AA without claiming that a component library alone makes a complete page conformant. Automated accessibility checks and keyboard behavior tests are release gates, supplemented by periodic manual VoiceOver with Safari and NVDA with Chromium checks for complex interactive components.
