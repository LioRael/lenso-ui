# Read a visual reference

Record the reference, viewport, theme, direction and important states. Inspect
its rendered frame, hierarchy, spacing, typography, surfaces and responsive
behavior. Identify assets that cannot be reused and preserve applicable licenses
for any adapted source.

Compare like with like: match viewport, content and state where possible, and
state differences in fonts, materials or rendering engines. If the reference is
unavailable, describe the missing evidence and avoid claiming visual parity.
