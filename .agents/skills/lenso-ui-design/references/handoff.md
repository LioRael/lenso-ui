# Delegate implementation, keep design ownership

Delegate independent implementation only after the shared visual specification
is settled. The design owner keeps cross-page geometry and final rendered
review; workers implement bounded slices rather than choosing separate styles.

Each assignment includes:

- Exact owned files and exported interface.
- Reference capture/source revision and approved representative screen.
- Frame and pane dimensions, responsive behavior and spacing hierarchy.
- Typography, semantic theme roles and required native parts.
- Sample content and meaningful interactions, including local-only boundaries.
- State, theme and viewport acceptance checks.
- Which decisions remain open and who owns them.

Link the shared specification instead of repeating variant palettes or token
tables in every assignment. The implementation agent queries the installed
component contract rather than receiving a stale hand-written API inventory.

The owner integrates and compares screenshots before accepting a worker's
completion. “Compact dashboard”, “polished inbox” and “use the same components”
are briefs, not sufficient implementation specifications.
