# @lenso/fonts

`@lenso/fonts` is a private, optional font integration boundary. The current package exposes approved fallback-stack metadata only; it does not ship redistributable WOFF2 assets and is not part of the public fixed release group.

Font assets and their original OFL notices will be added only after the asset provenance bundle is committed and verified. Consumers should provide their own licensed font assets or use the fallback stacks emitted by `@lenso/tokens`.
