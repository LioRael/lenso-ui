# @lenso/tokens

Generated primitive and semantic tokens for Lenso UI. The DTCG `src/foundation.json`, `src/semantic.json`, `src/themes/*.json`, and `src/lenso.resolver.json` documents are authoritative. `src/tokens.json`, TypeScript, StyleX, CSS, and contract artifacts are generated and must not be edited directly.

Semantic tokens remain the recommended choice for product UI and theme-aware components. Public color primitives are available for custom composition and precise palette control; consumers that bind primitives directly own their Light/Dark behavior.
