# @lenso/primitives

Headless, style-free product primitives. The MVP surface contains the composable Sidebar state and accessibility model.

Import `Sidebar` from `@lenso/primitives/sidebar`. Its compound parts support controlled and uncontrolled state, independent left and right panels, nested sidebars, keyboard dismissal, and focus restoration without imposing CSS or an animation runtime. Consumers own composition and visuals; the Lenso registry includes one styled Sidebar Recipe as an editable starting point.
