# ComboBox live examples

The local `.tsx` modules demonstrate Lenso's ComboBox contract. The
[current example catalog](../../../../content/example-catalog.json) and generated
live manifest own their public registration.

Base UI owns filtering, selection, focus, controlled state and native form
values. `shared.tsx` supplies the common data and composition. Multiple selection
uses native chips and removal controls; asynchronous loading cancels stale
requests and exposes loading and failure states. Layout uses StyleX.

Use the current docs checks in
[`CONTRIBUTING.md`](../../../../../../CONTRIBUTING.md) to verify changes.
Registration alone does not prove browser behavior, geometry or visual parity.
