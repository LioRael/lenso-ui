The stable registry alias at `/r/{name}.json` is regenerated from the current repository source. A versioned snapshot is immutable and is generated during the release versioning workflow. The stable alias and the immutable snapshot therefore represent different responsibilities: current development output versus reproducible release input.

Public changes to component APIs, semantic token names, registry item names, or material visual contracts require a Changeset. See the repository [MVP contract](https://github.com/LioRael/lenso-ui/blob/main/MVP.md) and [architecture guide](https://github.com/LioRael/lenso-ui/blob/main/docs/architecture.md) for the durable constraints.
