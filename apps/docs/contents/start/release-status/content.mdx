This address is no longer maintained as a product page. Start with
[Installation](/start/installation) to add the managed packages, or choose
[Package vs Registry](/start/package-vs-registry) when you need editable source.

Package metadata is the source of truth for compatible versions. Published
changes and migration notes live in the repository
[release history](https://github.com/LioRael/lenso-ui/releases). Versioned registry
snapshots remain available at `/r/v/{version}/{name}.json` for reproducible installs.
