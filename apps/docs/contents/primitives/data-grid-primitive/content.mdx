  <Guidance>
    <GuidanceBlock title="Choose the right layer">
      <ul>
        <li>Use <code>useDataGrid</code> if your product owns its grid markup and appearance. It returns the TanStack table instance plus <code>commitCells</code>.</li>
        <li>Use <code>@lenso/ui/data-grid</code> for the ready-made Lenso appearance and interaction surface. Ordinary read-only records still belong in Data Table.</li>
      </ul>
    </GuidanceBlock>
    <GuidanceBlock title="Commit contract">
      <ul>
        <li>Provide stable row IDs and immutable <code>rows</code>. Without <code>onRowsChange</code>, edits are rejected. Set <code>readOnly</code> to make that intent explicit.</li>
        <li><code>commitCells</code> checks all edits before calling <code>onRowsChange</code>. A failed validation rejects the batch without applying a partial update.</li>
        <li>Use <code>onCellEditComplete</code> for every cell, a column's callback for that column, <code>cellEvents</code> for exact row-and-column targets, and <code>onRowEditComplete</code> once per affected row in a transaction.</li>
        <li>Cell selection follows TanStack Table's range model. Bind a cell's start handler to mouse down and its extend handler to mouse enter if you build custom markup.</li>
      </ul>
    </GuidanceBlock>
  </Guidance>

<CodeExample
  code={String.raw`import { useDataGrid } from "@lenso/primitives/data-grid";

const { table, commitCells } = useDataGrid({
    rows,
    columns,
    getRowId: (row) => row.id,
    onRowsChange: (nextRows) => setRows([...nextRows]),
    onCellEditComplete: (change) => auditCell(change),
    cellEvents: [
      {
        rowId: "company-42",
        columnId: "status",
        onEditComplete: (change) => notifyStatusChange(change),
      },
    ],
});

commitCells([{ rowId: "company-42", columnId: "status", value: "Active" }]);`}
  description="Use the primitive when the application needs a custom rendering layer."
