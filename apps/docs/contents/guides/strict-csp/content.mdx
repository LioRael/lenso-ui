<CodeExample
  code={String.raw`import { CSPProvider } from "@lenso/ui/csp-provider"

<CSPProvider nonce={requestNonce}>
  <App />
</CSPProvider>`}
  description="Generate a nonce for each server response, include it in the policy header, and pass the same value to the provider."
  title="Wire the provider"
/>

  <Guidance>
    <GuidanceBlock title="Set the policy at the response boundary">
      <ul>
        <li>Include the nonce in <code>script-src</code> and <code>style-src-elem</code>.</li>
        <li>Keep the nonce request-scoped; do not use one static application-wide value.</li>
        <li>Use the application's existing policy for inline style attributes separately.</li>
      </ul>
    </GuidanceBlock>
    <GuidanceBlock title="When styles are already external">
      When your application supplies the required external component styles, pass
      <code>disableStyleElements</code> to prevent Base UI from creating inline style elements. This
      does not remove inline <code>style</code> attributes, which are controlled by
      <code>style-src-attr</code>.
    </GuidanceBlock>
  </Guidance>

`CSPProvider` is independent from `ThemeScope`, Toast, and component-specific providers. Add only
the boundaries your application needs.
