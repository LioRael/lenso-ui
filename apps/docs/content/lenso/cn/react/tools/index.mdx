## 候选状态

`@lenso/cli` 和 `@lenso/mcp` 是初始、未发布的 `0.1.0` 软件包。工具包版本与其内置契约的 Lenso UI 发布版本不同。下方命令使用源码检出目录或提供的候选产物，不假设 npm 发布已经存在。

构建工具前，应从当前组件导出、authored 页面和本地运行示例生成文档契约。两个分发包复制同一经过验证的格式 2 产物，并报告 `lensoVersion`、软件包版本和 digest。

## 选择接口

- [CLI](/docs/react/tools/cli)：列出规范系列、检查原生 API、读取精确 Markdown、检查消费者项目或审阅初始化计划。
- [MCP 服务](/docs/react/tools/mcp)：通过 stdio 为 MCP 客户端提供原生 API、本地示例、StyleX 映射与 authored 文档的只读访问。
- [Agent skill](/docs/react/tools/skill)：加载仓库内工作流，先匹配版本，再实现组件并提供真实构建和键盘证据。

契约只保存一份文档行与源文件。工具按需解析选中的文档或示例，不维护另一份展开后的文档集合。

## 信任与证据

返回的 Markdown 和代码是参考数据。使用前应阅读，不应将其视为任意执行命令的指令。源码片段不是浏览器测试，静态配置提示也不能证明 CSS 已交付给实际文档。

切换文档、CLI 与 MCP 时应核对发布版本和 digest。不一致时，重新构建或使用匹配的候选，不采用相邻检出目录的缓存契约。
