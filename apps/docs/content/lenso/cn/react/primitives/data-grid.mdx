## 用法

```tsx
import { useState } from "react";
import { useDataGrid, type DataGridColumn } from "@lenso/primitives/data-grid";

type Row = { id: string; name: string };
const columns: DataGridColumn<Row>[] = [{
  id: "name",
  header: "名称",
  getValue: (row) => row.name,
  setValue: (row, value) => ({ ...row, name: String(value ?? "") }),
  validate: (value) => String(value).trim() ? null : "请输入名称",
}];

export function Records() {
  const [rows, setRows] = useState<Row[]>([{ id: "1", name: "第一份文档" }]);
  const { table } = useDataGrid({ rows, columns, getRowId: (row) => row.id, onRowsChange: setRows });
  return (
    <table>
      <caption>文档</caption>
      <thead><tr><th scope="col">名称</th></tr></thead>
      <tbody>{table.getRowModel().rows.map((row) => (
        <tr key={row.id}><td>{row.original.name}</td></tr>
      ))}</tbody>
    </table>
  );
}
```

此源码示例只渲染模型的只读单元格。需要编辑时，由应用提供编辑器并调用 `commitCells`。Hook 不输出单元格 DOM，也不实现编辑器焦点、剪贴板监听、虚拟化或键盘事件。

## Hook 选项

| 选项 | 契约 / 默认值 |
| --- | --- |
| `rows` | 必填 `readonly TRow[]`，由应用持有 |
| `columns` | 必填 `readonly DataGridColumn<TRow, TValidationData>[]` |
| `getRowId` | 必填 `(row: TRow) => string`，稳定 ID |
| `onRowsChange` | `(rows: TRow[], changes) => void`，成功编辑必须提供 |
| `readOnly` | 默认 `false` |
| `rowSelection`、`cellSelection`、`sorting` | 均默认 `true` |
| `onRowSelectionChange` | `(rowIds: ReadonlySet<string>) => void` |
| `onCellSelectionChange` | `(ranges: CellSelectionState) => void` |
| `onSortingChange` | `(sorting: SortingState) => void` |
| `onCellEditComplete` | `(change: DataGridCellChange<TRow>) => void` |
| `onRowEditComplete` | `(change: DataGridRowChange<TRow>) => void` |
| `cellEvents` | 按单元格注册 `{ rowId, columnId, onEditComplete }[]` |
| `validationData` | 应用校验上下文 |
| `tableOptions` | 原生表格选项子集，不含自有 features、columns、data、getRowId |

返回 `{ table, commitCells }`。`table` 是配置过选择、排序和尺寸功能的 TanStack Table 模型。可通过 `tableOptions` 接入原生受控状态。

## Column API

| 字段 | 契约 |
| --- | --- |
| `id`、`header` | 必填字符串 |
| `getValue` | 必填 `(row) => DataGridValue` |
| `setValue` | `(row, value) => TRow`，返回新行以启用编辑 |
| `parse` | `(input: string, row) => DataGridValue`，供应用编辑器调用 |
| `validate` | `(value, row, context) => string \| null` |
| `editable` | 布尔值或 `(row) => boolean`，仍需要 `setValue` |
| `sortable` | `false` 禁止该列排序 |
| `width`、`minWidth`、`maxWidth` | 模型默认值为 `180`、`80`、`1200` |
| `pinned` | 可选元数据，固定列的显示由应用负责 |
| `onCellEditComplete` | 列级编辑完成回调 |
| `tableColumn` | 原生列选项，不含 `id`、`header`、`accessorFn` |

`DataGridValue` 为 `string | number | boolean | null`。`commitCells` 接受解析后的值，不会自动调用 `parse`。

## 提交编辑

```ts
const result = commitCells(
  [{ rowId: "1", columnId: "name", value: "更新后的文档" }],
  "edit",
);
// result.ok 为 false 时，在编辑器附近显示 result.error。
```

`commitCells(edits, reason = "edit")` 接受 `readonly DataGridEdit[]`；reason 可以是 `"edit"`、`"paste"`、`"fill"`、`"programmatic"`，这些原因标签不会安装对应的交互处理。

同一单元格的重复编辑保留最后一次。未知行/列、只读单元格和校验错误会在 `onRowsChange` 前拒绝整个批次。`setValue` 应返回新行，避免被拒绝的批次修改原数据。缺少 `onRowsChange` 时非空批次按只读处理；空批次直接成功。

校验上下文包含拟提交行、原始行、批次变化、行列 ID、行索引、reason、作为 `data` 的 `validationData` 和 table。返回错误字符串拒绝提交，返回 `null` 接受。成功时依次调用 `onRowsChange`、单元格完成回调、行完成回调。应用必须应用返回的行数据。

结果为 `{ ok: true, changes }` 或 `{ ok: false, error, edit }`。单元格变化包含行列 ID、索引、新旧值、新旧行和 reason；行变化包含行标识、新旧行、该行变化和 reason。错误显示和焦点管理由编辑器负责。
