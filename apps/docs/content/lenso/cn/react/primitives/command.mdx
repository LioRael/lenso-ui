## 用法

```tsx
import { Command } from "@lenso/primitives/command";

export function Commands({ onCreate }: { onCreate: () => void }) {
  return (
    <Command.Root>
      <Command.Input aria-label="查找命令" placeholder="输入命令…" />
      <Command.List>
        <Command.Empty>没有匹配的命令。</Command.Empty>
        <Command.Item value="create-document" onSelect={onCreate}>创建文档</Command.Item>
      </Command.List>
    </Command.Root>
  );
}
```

Command 将 Base UI Autocomplete 组合为始终展开的内联列表。浮动命令面板应放在 Dialog 中，由 Dialog 负责展开、焦点约束与关闭。Primitive 不注册全局快捷键。

## Root API

| 属性 | 类型 / 默认值 | 行为 |
| --- | --- | --- |
| `value`、`defaultValue` | 查询字符串，默认 `""` | 受控值 / 初始值 |
| `onValueChange` | `(value, details) => void` | 原生查询回调 |
| `items` | `readonly Value[]` | 数据集合 |
| `filteredItems` | `readonly Value[]` | 外部过滤后的集合 |
| `filter` | 原生过滤回调或 `false` | `false` 关闭内部过滤 |
| `autoHighlight` | 原生属性，默认 `"always"` | 高亮策略 |
| `keepHighlight` | 默认 `true` | 保留高亮 |
| `readOnly` | 默认 `false` | 同时阻止 `Item.onSelect` |

其他属性继承 `Autocomplete.Root.Props<Value>`；`inline`、`open`、`defaultOpen`、`onOpenChange`、`mode` 由 Command 管理，不向调用方开放。执行项目不会将标签写入查询。若希望执行后清空查询，由应用修改受控值。

## 部件与 Hook

| 导出 | 契约 |
| --- | --- |
| `Command` / `Command.Root` | 同一个根组件 |
| `Input` | 原生 Autocomplete 输入属性，保留 IME 组合输入 |
| `List` | 原生结果列表 |
| `Item` | 必填 `value: Value`，可选 `onSelect(value): void`，保留原生项目属性和 div ref |
| `Empty` | 无结果内容 |
| `Group`、`GroupLabel` | 分组与标签 |
| `Separator` | 分隔线 |
| `Collection` | 原生集合渲染 |
| `Status` | 状态播报 |
| `Clear` | 清空查询 |
| `Command.useFilter` / `useCommandFilter` | 原生 Autocomplete 过滤 Hook |

也可使用具名导出 `CommandRoot`、`CommandInput`、`CommandList`、`CommandItem`、`CommandEmpty`、`CommandGroup`、`CommandGroupLabel`、`CommandSeparator`、`CommandCollection`、`CommandStatus`、`CommandClear`。本地 props 类型见源码。

## 执行、键盘与异步结果

Base UI 管理高亮和输入框/列表键盘行为。IME 组合输入期间不会触发它的键盘处理。Item 先运行原生 `onClick`，再运行 `onSelect`；阻止默认行为或 Base UI handler 会取消执行。`readOnly` 阻止 `onSelect`，应用自己的 `onClick` 逻辑仍由应用负责。

对象值需要一致配置原生标签和集合属性。将动作放在 `onSelect` 中，为输入框提供标签。异步数据源由应用管理，可通过 `Status` 表达加载或错误。
