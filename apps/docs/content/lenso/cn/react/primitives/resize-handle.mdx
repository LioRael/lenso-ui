## 用法

```tsx
import { useState } from "react";
import * as stylex from "@stylexjs/stylex";
import { ResizeHandle } from "@lenso/primitives/resize-handle";

const styles = stylex.create({
  handle: { width: 8, minHeight: 160, backgroundColor: "currentColor" },
});

export function SplitPane() {
  const [width, setWidth] = useState(240);
  return (
    <div style={{ display: "flex" }}>
      <aside id="navigation-pane" style={{ width, flexShrink: 0 }}>导航</aside>
      <ResizeHandle
        aria-label="导航宽度"
        aria-controls="navigation-pane"
        min={160}
        max={400}
        value={width}
        onValueChange={setWidth}
        xstyle={styles.handle}
      />
      <main>内容</main>
    </div>
  );
}
```

将受控 `value` 应用到面板布局，在 `onValueChange` 中更新它。使用 StyleX 设置可见的命中区域与键盘焦点样式，并配置 StyleX 编译。示例中的运行时 `style` 属于面板，`xstyle` 属于分隔条。

## API

| 属性 | 类型 | 默认值 / 要求 |
| --- | --- | --- |
| `aria-controls` | `string` | 必填，对应面板 ID |
| `aria-label` / `aria-labelledby` | `string` | 提供可访问名称 |
| `value` | `number` | 必填，受控尺寸 |
| `min`、`max` | `number` | 必填，尺寸边界 |
| `onValueChange` | `(value, details) => void` | 必填，应用尺寸变化 |
| `onValueCommit` | `(value, details) => void` | 可选，交互结束时持久化 |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` |
| `step` | `number` | `16` |
| `inverted` | `boolean` | `false`，反转指针与方向键增量 |
| `disabled` | `boolean` | `false` |
| `onCollapseToggle` | `(event) => void` | 点击或 Enter 触发 |
| `xstyle` | `StyleXStyles` | 外观 |
| `render`、`ref` | Base UI render prop、元素 ref | 原生元素组合 |

`details` 包含 `{ value, delta, reason, event }`，`reason` 为 `"pointer"` 或 `"keyboard"`。指针变化回调的 delta 是当次移动量；指针提交回调的 delta 是从拖动起点算起的总变化量。键盘调整立即提交。指针释放、取消或失去捕获时结束拖动。边界会归一化，尺寸会限制在范围内。

## 方向与键盘

方向描述分隔条本身。**竖直**分隔条使用水平指针移动和 Left/Right 调整宽度；**水平**分隔条使用竖直指针移动和 Up/Down 调整高度。Home、End 到达边界。提供 `onCollapseToggle` 时 Enter 和点击触发切换，拖动后的紧接点击不会切换。

分隔条负责 separator 语义、焦点、指针捕获与 ARIA 数值。样式状态属性为 `data-disabled`、`data-dragging`、`data-orientation`；render 状态包含 `disabled`、`dragging`、`orientation`、`value`。布局、折叠状态、持久化和动画由应用负责。
