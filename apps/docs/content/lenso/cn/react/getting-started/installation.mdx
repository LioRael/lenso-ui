先选择[框架集成](/docs/react/getting-started/frameworks)：[Vite / Rolldown](/docs/react/getting-started/frameworks#vite-and-rolldown) 或 [Next.js App Router](/docs/react/getting-started/frameworks#nextjs-app-router)，再完成以下安装。

## 环境要求

使用符合 `@lenso/ui` 公布的 peer 范围的 React 和 React DOM，以及 `@stylexjs/unplugin` 支持的打包器。Lenso 不需要 Tailwind。

## 软件包

React 包名为 `@lenso/ui`，主题与组件样式映射由 `@lenso/tokens` 提供。UI 与 tokens 应使用匹配的 Lenso 版本。React 和 React DOM 必须满足 React 包公布的 peer 范围。

```sh
bun add @lenso/ui @lenso/tokens @stylexjs/stylex
bun add -d @stylexjs/unplugin
```

## 主题样式表

在实际渲染文档的布局中加载：

```tsx
import "@lenso/tokens/styles.css";
```

在文档或所在表面设置主题的 `light` 或 `dark` 作用域。Portal 中的组件需要相同主题作用域；未指定自定义容器时，Lenso 的原生 portal 包装会保留它。仅在兄弟布局加载的样式表不能为此文档提供样式。

可以从一个实际操作开始：

```tsx
import { Button } from "@lenso/ui";

export function App() {
  return <Button onClick={() => console.log("Saved")}>保存更改</Button>;
}
```

依赖生产样式前，完成下方构建集成。

## 应用 StyleX

使用官方 StyleX 插件统一编译 Lenso 发布的声明和应用样式：

```ts
import stylex from "@stylexjs/unplugin";

const options = {
  dev: false,
  runtimeInjection: false,
  useCSSLayers: false,
  lightningcssOptions: { exclude: 4 },
  unstable_moduleResolution: {
    type: "commonJS" as const,
    rootDir: import.meta.dirname,
  },
};

// Vite 配置中的插件：
const plugins = [stylex.vite(options)];
```

Rolldown 使用官方集成，Next 使用官方 Babel/PostCSS 配置。源码扫描、SSR 与样式表导入要求见[框架指南](/docs/react/getting-started/frameworks)。

## 验证消费者

构建应用，打开生产路由，确认主题 CSS 与合并后的 StyleX 规则在控件呈现前已加载。检查本地 `xstyle` 覆盖与 portal 覆盖层。开发环境样式可能掩盖生产 CSS 交付缺失。
