Lenso UI 是一个 React 组件库，提供共享主题、类型化组件部件，以及原生键盘和焦点行为。从 `@lenso/ui` 导入组件，通过 `@lenso/tokens` 加载主题，再使用 StyleX 自定义外观。

## 为什么使用 Lenso UI？

- **开箱即用的组件。** 按钮、表单、导航和覆盖层共享主题与组件变体。
- **可组合的部件。** 使用公开部件构建对话框、菜单或字段，而不替换连接它们的交互行为。
- **类型化样式。** 通过 `xstyle` 定义应用样式，通过语义 CSS 变量设置颜色与表面。
- **原生交互。** 普通交互组件采用 Base UI；日期、时间和颜色组件采用 React Aria 的值模型与上下文。组件 API 表展示实际属性与事件。

## 开始构建

按照[快速开始](/docs/react/getting-started/installation)安装软件包、加载主题并配置构建适配器，然后渲染第一个组件：

```tsx
import { Button } from "@lenso/ui";

export function App() {
  return <Button onClick={() => console.log("已保存")}>保存更改</Button>;
}
```

浏览[组件](/docs/react/components)查看用法、示例和 API。通过[样式](/docs/react/getting-started/stylex)自定义组件，通过[组合](/docs/react/getting-started/architecture)安排组件部件。

## Lenso 工具

[CLI](/docs/react/tools/cli)、[MCP 服务器](/docs/react/tools/mcp)和[代理技能](/docs/react/tools/skill)提供同一份组件 API、样式和文档。工具版本及契约应与 UI 版本匹配。目前的工具候选可从源码仓库构建；这些说明不假设它们已发布到 npm。

## 常见问题

### Lenso UI 需要 Provider 吗？

不需要全局 UI Provider。在应用入口加载主题样式表，设置明亮或深色作用域，并将依赖上下文的部件放在组件根部内。

### 可以自定义组件吗？

可以。使用组件变体、组合公开部件，或通过 `xstyle` 添加 StyleX 声明。[主题](/docs/react/getting-started/theming)介绍共享 CSS 变量。

### 支持 TypeScript 吗？

组件导出原生属性和 ref 类型。API 参考从当前软件包生成，并包含回调签名。

### 无障碍支持如何？

原生组件提供键盘、焦点和语义行为。应用仍负责标签、内容、对比度和自定义组合。请一起测试这些行为；组件库不为应用提供认证。
