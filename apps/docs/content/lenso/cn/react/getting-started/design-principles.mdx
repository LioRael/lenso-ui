## 共享视觉语言

使用主题的语义颜色、表面与间距，而不是逐个组件重新选择数值。变体描述外观；切换变体不应替换组件的激活或选择行为。

## 组合，而不是模拟

通过公开部件安排组件内容。让控件、标签与覆盖层通过根部连接。带样式的 `div` 不能替代原生按钮、菜单项或对话框。

## 保留交互

采用原生 `render` 契约时，转发传入属性与 ref。保留事件处理器、状态属性和无障碍关系。普通控件保留 Base UI 契约；日期、时间和颜色部件保留 React Aria 上下文。

## 验证应用

在实际交付的界面中检查标签、键盘导航、焦点恢复和对比度。测试明暗主题与减少动态效果。组件源码示例不能证明自定义组合的行为。
