## 从任务开始

先让人看到可以尝试的示例、需要编辑的设置或需要浏览的内容。把辅助说明放在相关操作附近，详细 API 随后提供。

## 对齐相关内容

标签、同级项目和图标使用共同的起始线。缩进表示真实的子级关系；相邻间距由一个容器负责。窄屏与较大文字下重新排列内容，保留可读性。

## 明确表面的职责

区分页面背景、分组内容、编辑控件和浮动导航。分组拥有背景与外圆角，内部行与控件共享表面。为独立任务或交互边界添加容器。

使用语义颜色表达内容、交互与状态。检查浅深色外观，持续保留错误说明和字段关联。

## 组合熟悉的控件

通过公开部件连接标签、控件、说明与错误。采用原生 render 契约时转发属性和 ref，保留编辑、选择、键盘操作、焦点恢复和减少动态效果支持。

## 验证实际应用

在实际页面中检查主要任务、指针与键盘、焦点恢复、错误内容、浅深色、窄屏及较大文字。涉及对齐或对比度时进行测量。源码片段、类型检查和 DOM 测试不能单独证明呈现与可用性。

## 选择字段组件

| 需求 | 组件与职责 |
| --- | --- |
| 编辑短文本 | Input 提供编辑控件。 |
| 编辑长文本 | TextArea 提供多行编辑。 |
| 为单个字段提供标签与验证 | TextField 关联标签、控件、说明和错误。 |
| 对相关设置分组 | Fieldset 提供图例并对相关控件分组。 |
| 提交并验证多个字段 | Form 管理提交与字段错误。 |

表单提交见 [Form](/docs/react/components/form)，单个字段的组合见 [TextField](/docs/react/components/textfield)。
