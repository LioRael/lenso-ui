## 当前版本

文档标题区域与生成契约从 `packages/react/package.json` 读取当前版本。主题包应来自匹配的 Lenso 发布。此次重构面向下一个 `0.9.0` 候选；这个目标不是发布公告。

使用旧包清单的构建不能标记为未来候选。合并软件包修改后，应重新生成文档和契约。

## 公开名称

`Menu` 是弹出命令菜单系列，没有公开 Dropdown 兼容导出。历史名称可以保留在私有来源记录和原始示例引用标识中。旧文档地址的重定向只是导航便利，不是 API 别名。

原生 API 变化应依据实际导出的 TypeScript 契约与运行行为作兼容性决策。上游库版本号不是 Lenso 兼容承诺。

## 参考来源

固定视觉参考为 HeroUI v3.2.6。它的历史版本和 v2 到 v3 迁移说明不是 Lenso 发布或 Lenso 迁移指南，不出现在公开导航、搜索、站点地图或复制 Markdown 中。

保留许可证声明与来源哈希，使派生关系可审计，而不把参考内容变成产品公开文档。

## 可复现消费者

文档和工具使用相同版本化 authored 索引与原生 API。必须从当前源码生成，而不是采用相邻检出目录的生成结果。修改公开名称时保留完整示例范围和缺失引用检查；部分浏览器运行必须明确标记为部分验证。
