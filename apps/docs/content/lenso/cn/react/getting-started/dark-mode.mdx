## 选择主题

默认主题支持 `.light`、`.dark`、`data-theme="light"` 和 `data-theme="dark"` 作用域：

```html
<html class="dark">
  <!-- 应用内容 -->
</html>
```

同时只选用一个作用域。主题更新背景、前景、表面和字段变量，并设置浏览器的 `color-scheme`。

## 系统偏好与持久化

应用负责主题选择。没有保存偏好时读取 `prefers-color-scheme`，持久化用户显式选择，并在首次绘制前应用，避免闪现错误主题。Lenso 不会安装主题 Provider 或存储策略。

服务端渲染应用应协调初始文档类名与客户端主题控制器。不要在服务端渲染时读取浏览器存储。

## 检查完整界面

在两种主题中检查控件、代码块、覆盖层与自定义表面。Portal 组件应继承所需作用域，自定义图片可能需要显式深色版本。纯图标主题切换器应具有无障碍标签。
