## Vite and Rolldown

Use `@stylexjs/unplugin` directly. Lenso ships ordinary modules containing StyleX declarations. The application compiler sees library and application styles in one graph. Import `@lenso/tokens/styles.css` for theme/base CSS. No package metadata artifact or Lenso build adapter is required.

```ts
import stylex from "@stylexjs/unplugin";
const plugins = [stylex.vite({
  dev: false,
  runtimeInjection: false,
  useCSSLayers: false,
  lightningcssOptions: { exclude: 4 },
  unstable_moduleResolution: { type: "commonJS" },
})];
```

Use `stylex.rolldown` for Rolldown. Preserve `:dir()` when choosing Lightning CSS targets.

For Vite SSR, compile the source packages instead of externalizing them:

```ts
ssr: { noExternal: ["@lenso/ui", "@lenso/tokens", "@lenso/glass"] }
```

Include `@lenso/docs` when using the documentation framework. Plain Node imports do not compile StyleX declarations. Styles used only on the server must also enter the application's CSS compilation; a client-only module graph does not establish their delivery.

## Next.js App Router

Use the official Babel and PostCSS plugins. Include tokens in `transpilePackages`.

```ts
// next.config.ts
export default { transpilePackages: ["@lenso/tokens"] };
```

```json
{
  "presets": ["next/babel"],
  "plugins": [["@stylexjs/babel-plugin", {
    "dev": false,
    "runtimeInjection": false,
    "treeshakeCompensation": true,
    "unstable_moduleResolution": { "type": "commonJS" }
  }]]
}
```

Save this as `babel.config.json`. Generate CSS from application sources and shipped tokens modules:

```js
// postcss.config.cjs
const path = require("node:path");
const babel = require("./babel.config.json");
module.exports = {
  plugins: {
    "@stylexjs/postcss-plugin": {
      include: [
        "./src/**/*.{js,jsx,ts,tsx}",
        "./app/**/*.{js,jsx,ts,tsx}",
        "./components/**/*.{js,jsx,ts,tsx}",
        path.join(path.dirname(require.resolve("@lenso/tokens/package.json")), "dist/**/*.js"),
      ],
      babelConfig: {
        babelrc: false,
        configFile: false,
        parserOpts: { plugins: ["typescript", "jsx"] },
        plugins: babel.plugins,
      },
    },
  },
};
```

```css
/* globals.css */
@import "@lenso/tokens/styles.css";
@stylex;
```

Import this stylesheet from every root layout and custom `global-error` or `global-not-found` document that replaces the layout. Next owns CSS delivery, hashing and manifests. Extend `include` for other source directories and server-only declarations.

`init --framework next` generates these ordinary configuration files. Static `check` diagnostics are hints; verify your framework build and rendered pages. Repository dependency patches fix stale CSS after declaration removal and repeated Babel loading in upstream 0.19.1. Constant values and media-query keys use upstream invalidation without a local override. Independent installations must verify their upstream version.

[Official Next.js integration](https://stylexjs.com/docs/learn/installation/nextjs/), [official Vite integration](https://stylexjs.com/docs/learn/installation/vite/).
