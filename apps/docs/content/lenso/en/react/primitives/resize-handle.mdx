## Usage

```tsx
import { useState } from "react";
import * as stylex from "@stylexjs/stylex";
import { ResizeHandle } from "@lenso/primitives/resize-handle";

const styles = stylex.create({
  handle: { width: 8, minHeight: 160, backgroundColor: "currentColor" },
});

export function SplitPane() {
  const [width, setWidth] = useState(240);
  return (
    <div style={{ display: "flex" }}>
      <aside id="navigation-pane" style={{ width, flexShrink: 0 }}>Navigation</aside>
      <ResizeHandle
        aria-label="Navigation width"
        aria-controls="navigation-pane"
        min={160}
        max={400}
        value={width}
        onValueChange={setWidth}
        xstyle={styles.handle}
      />
      <main>Content</main>
    </div>
  );
}
```

The handle is controlled: apply `value` to your pane layout and update it in `onValueChange`. Give the handle a visible hit area and a keyboard focus treatment through your StyleX styles. Compile StyleX in your application. The example's runtime `style` belongs to the pane, while `xstyle` styles the handle.

## API

| Prop | Type | Default / requirement |
| --- | --- | --- |
| `aria-controls` | `string` | Required pane element ID |
| `aria-label` / `aria-labelledby` | `string` | Supply an accessible name |
| `value` | `number` | Required controlled size |
| `min`, `max` | `number` | Required bounds |
| `onValueChange` | `(value, details) => void` | Required; applies size updates |
| `onValueCommit` | `(value, details) => void` | Optional; persistence after an interaction |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` |
| `step` | `number` | `16` |
| `inverted` | `boolean` | `false`; reverses pointer/arrow direction |
| `disabled` | `boolean` | `false` |
| `onCollapseToggle` | `(event) => void` | Optional click / Enter handler |
| `xstyle` | `StyleXStyles` | Visual treatment |
| `render`, `ref` | Base UI render prop, element ref | Native element composition |

`details` contains `{ value, delta, reason, event }`; `reason` is `"pointer"` or `"keyboard"`. Pointer changes report movement deltas; pointer commit reports the total delta from drag start. Keyboard adjustments commit immediately. Pointer release, cancellation and loss of capture finish the drag. Bounds are normalized and values are clamped.

## Orientation and keyboard

Orientation describes the separator itself. A **vertical** separator uses horizontal pointer movement and Left/Right arrows to change pane width. A **horizontal** separator uses vertical movement and Up/Down arrows to change pane height. Home and End move to the bounds. Enter invokes `onCollapseToggle` when supplied; a click also invokes it, except immediately after a drag.

The handle owns separator semantics, focusability, pointer capture and ARIA value attributes. It exposes `data-disabled`, `data-dragging` and `data-orientation` for state styling. Render state includes `disabled`, `dragging`, `orientation` and `value`. The application owns layout, collapse state, persistence and any animation.
