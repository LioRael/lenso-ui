## Use the package

Load the generated token and component styles once at your application entry point.

```tsx
import "@lenso/tokens/styles.css";
import "@lenso/ui/styles.css";
```

Continue with the <DocLink to="start/quick-start">quick start</DocLink> or inspect the <DocLink to="components/button">Button component</DocLink>.
