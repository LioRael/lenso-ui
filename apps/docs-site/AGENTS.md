# Public documentation

`apps/docs-site` is the public Astro consumer of `@lenso/docs`. Add pages under
`content/docs/<tab>/`; the file path determines the route. Put order and group
labels in the nearest `meta.ts`. Keep the page title and description in
frontmatter. Use `DocLink` for internal content links so subpath builds work.

Interactive examples belong under `src/components/docs` and hydrate in MDX with
`client:load`. Keep the example tied to the public `@lenso/ui` subpath. Shared
documentation layout, search, and content conventions belong in
`packages/docs`; page-specific demos and application data belong here.

`public/r` is generated by the registry builder. Update its source and run
`pnpm generate` rather than editing the JSON files. The former Next app under
`apps/docs` is a comparison reference, not the source for new content.
