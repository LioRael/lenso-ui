    <GuidanceBlock title="Choose Button when">
      <ul>
        <li>Use Button for explicit, user-initiated actions.</li>
        <li>Keep one primary action per focused surface.</li>
        <li>Use Ghost only for low-emphasis actions in toolbars or compact groups.</li>
      </ul>
    </GuidanceBlock>
    <GuidanceBlock title="Labels and feedback">
      <ul>
        <li>Use a clear action label; icon-only actions need an accessible name.</li>
        <li>Keep focus-visible and loading feedback intact.</li>
        <li>Disabled actions must not be the only explanation.</li>
      </ul>
    </GuidanceBlock>
  </Guidance>
