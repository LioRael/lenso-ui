The playground previews search and selection. Choosing a sample command fills the input; it does not change application data.

  <Guidance>
    <GuidanceBlock title="Choose Command Menu when">
      <ul>
        <li>Use for fast, keyboard-first actions and navigation.</li>
        <li>Compose inside a Dialog when the menu should be modal.</li>
      </ul>
    </GuidanceBlock>
    <GuidanceBlock title="Accessibility">
      <ul>
        <li>Combobox semantics, filtering, and arrow-key navigation come from Base UI.</li>
      </ul>
    </GuidanceBlock>
  </Guidance>

  <CodeExample
    code={String.raw`import { CommandMenu } from "@lenso/ui/command-menu";

<CommandMenu.Root items={commands}>
    <CommandMenu.Panel>
      <CommandMenu.Search>
        <CommandMenu.Input placeholder="Type a command or search…" />
      </CommandMenu.Search>
      <CommandMenu.List>
        {(command) => <CommandMenu.Item value={command}>{command}</CommandMenu.Item>}
      </CommandMenu.List>
    </CommandMenu.Panel>
</CommandMenu.Root>;`}
    description="Every visual part remains replaceable through the composition API."
  />
