# Your first guide

Use headings to make long pages scannable, and keep each page focused on one task.

<Steps>
  <Step>
    ### Create a page

    Add an `.md` or `.mdx` file under `content/`.

  </Step>
  <Step>
    ### Add it to navigation

    List its content path in `docs.config.ts`.

  </Step>
  <Step>
    ### Preview it

    Run `pnpm dev` after installing dependencies.

  </Step>
</Steps>
